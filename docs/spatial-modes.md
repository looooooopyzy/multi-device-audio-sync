# 双模式播放设计

## 模式

- `normal`：原有模式。Windows 与浏览器各播放完整立体声 PCM，不改变声学校准时间。
- `spatial`：根据房间图中各个**有效扬声器**的横坐标计算左右声道权重。有效扬声器指已启用的 Windows 实体输出，或已启用播放且收集到足够时钟样本的浏览器设备。校准音与测试提示音仍直接在两声道播放，不参与音乐混音。

房间图的听音点固定在中央。横坐标范围 0～100，决定左右声道分配；纵坐标仅用于记录相对方位。左右相距不足 10 个坐标单位或有效扬声器少于两台时，所有设备继续播放完整立体声。

对于有效设备 *i*，先取其相对横坐标 `tᵢ=(xᵢ−min(x))/(max(x)−min(x))`，再令左声道原始权重为 `1−tᵢ`、右声道原始权重为 `tᵢ`。各声道分别按权重平方和归一化。空间模式在每台设备上将两个输入声道混为一条单声道信号，并同时送到该设备的左右输出，避免设备内部左右扬声器再形成另一层声像。模式切换与拖动位置时，Windows 在一个 10 ms PCM 块内渐变，浏览器在下一个排程批次内渐变。

## 控制与存储

浏览器页面通过现有 WebSocket 发送 `MODE|normal` / `MODE|spatial` 和 `POSITION|设备ID|x|y`。主控向所有页面广播 `ROOM|模式|Windows x|Windows y|Windows启用|设备ID|名称|x|y|启用...`，再向各页面分别发送 `MIX|normal/spatial|左权重|右权重`。主控将模式和坐标写入本机 `.local-certs/spatial-layout.txt`，启动时恢复。旧版浏览器忽略新消息，仍可播放原有音频；使用空间模式时所有设备应刷新到新版页面。

声道分配基于现有 PCM，不改变网络包格式、缓冲、时钟同步或声学延迟值。声学校准对应某个听音点；设备或听音点移动后应重新校准。不同硬件扬声器的音色、低频与音量仍有差异，本阶段不做频响均衡或自动定位。
